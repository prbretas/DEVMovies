## 📋 Sobre

DEVMovies é uma plataforma web gratuita e de código aberto para descobrir filmes, séries, animes, jogos e conteúdo de TV online. O projeto integra múltiplas APIs para oferecer um catálogo rico e atualizado de entretenimento.

### ✨ Features

- 🎬 Catálogo de **Filmes** com ratings do IMDB
- 📺 Seção de **Séries** curadas
- 📚 Base de dados de **Animes**
- 🎮 Recomendações de **Jogos**
- 📡 Conteúdo **TV Online**
- 📱 Design **Responsivo**
- ⚡ Interface **Rápida e Fluida**
- 🎨 **Open Source** com MIT License

## 🚀 Quickstart

### Opção 1: Ver Online
Visite [prbretas.github.io/DEVMovies](https://prbretas.github.io/DEVMovies/)

### Opção 2: Executar Localmente

**Pré-requisitos:**
- Git
- Node.js 14+ (para ferramentas)
- Browser moderno

**Instalação:**

```bash
# 1. Clone o repositório
git clone https://github.com/prbretas/DEVMovies.git
cd DEVMovies

# 2. Configure variáveis de ambiente
cp .env.example .env
# Edite .env com suas API keys

# 3. Inicie servidor local
npm start
# ou
python -m http.server 8000

# 4. Abra no browser
# http://localhost:8000
```
